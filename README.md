# 씬플로우 · 모바일 TRPG 시나리오 진행기

**코코포리아용 반자동 시나리오 보조 웹앱 (v1.2)**입니다. 코코포리아 자체를 수정하거나 채팅을 자동 전송하지 않습니다. 휴대폰에서 지문을 **한 번 누르고 복사 → 코코포리아 채팅에 붙여넣기** 하는 방식입니다.

## 포함 기능

- TXT / MD / PDF 원문 불러오기, 원문 붙여넣기, JSON 백업 복원
- `# 제목`, `##제목`처럼 `#`로 시작하는 줄을 **새 장면**으로 분할
- 별도 줄의 `ENDING A`, `ENDING B`, `ENDING C` 또는 `# ENDING A` 등을 **엔딩 장면**으로 자동 분할
- 엔딩이 2개 이상이면 엔딩을 고르는 분기 버튼 자동 생성(수동 이동 가능)
- `판정: 관찰력`, `관찰력 판정`, 문장 속 `판정` 뒤에 이어지는 `성공:` / `실패:`를 **결과 선택형 판정**으로 자동 분류
- 기존 `[판정: 항목]`, `[성공]`, `[실패]`, `[분기]`, `이름: 대사` 표기도 계속 지원
- 지문·NPC 대사·선택 결과를 **원클릭 복사**, NPC 화자 이름 포함/제외
- 성공·실패 및 자유 선택지, 선택 시 나올 결과 지문, 다음 장면 지정
- 여러 엔딩을 장면으로 관리하고 선택지로 이동 (엔딩 도착 시 자동으로 다음 엔딩 진행하지 않음)
- 자유 RP 대기, 이전/다음, 장면으로 이동, 스포일러 장면 이름 숨김
- 장면/이벤트/판정/분기/대사 **모바일 편집기**
- 시나리오 **원문 검색** 및 원문 전체 복사
- **자동 로컬 저장**(IndexedDB 우선) 및 JSON 백업/TXT 내보내기
- PWA 홈 화면 추가, 일반 플레이는 오프라인에서도 사용 가능(HTTPS 배포 및 최초 로딩 이후)

## 코코포리아에서 사용하는 방법

1. 씬플로우에서 시나리오를 열거나 등록합니다.
2. [플레이] 탭에서 **지문 복사**를 누릅니다.
3. 코코포리아로 전환해 원하는 시스템/NPC 캐릭터의 채팅 입력창에 **붙여넣고 전송**합니다.
4. 자유롭게 RP한 후 씬플로우로 돌아와 **다음**을 누릅니다.
5. **판정** 화면에서는 실제 코코포리아 다이스 결과에 맞춰 성공/실패를 누르고, 결과 지문을 복사합니다.
6. **분기** 화면에서는 해당 선택지를 누르고, 출력/복사 후 대상 장면으로 진행합니다.

### 자동 분석용 간단한 표기법

```
# 장면 1: 저택의 복도
문 너머에서 발소리가 들린다.

집사: 손님, 이쪽은 출입 금지입니다.

관찰력 판정
성공: 손잡이에 작은 흠집이 있다는 사실을 눈치챈다.
실패: 특별한 단서를 찾지 못한다.

# 마지막 선택
어느 쪽을 선택할까?

ENDING A: 탈출
탐사자가 저택을 떠난다.

ENDING B: 잔류
탐사자가 저택에 남는다.
```

**중요:** `#`는 줄 맨 앞의 장면 구분 기호로 인식합니다. 제목 없는 `#`에는 임시 장면 번호가 붙습니다. `ENDING A/B/C`도 별도 줄(또는 `#` 제목)일 때 인식합니다. `성공:` / `실패:`는 앞선 판정과 결합됩니다. 원본 시나리오의 다양한 표현을 완벽하게 자동 해석하지는 않습니다. 일반 원문은 초안으로만 분류하며, 복잡한 조건·다중 분기·엔딩 연결은 [편집] 탭에서 직접 설정해야 합니다. 엔딩 버튼은 자동 생성되지만, 시나리오의 구체적인 조건에 맞는 선택지는 필요에 따라 직접 수정하세요.

## 사용법 A · HTML 파일로 간단히 실행

함께 제공된 `씬플로우_바로실행.html` 파일을 브라우저에서 엽니다. 별도의 설치가 필요하지 않습니다. Android 기기의 파일 앱에서 열기가 안 될 경우, Chrome에서 파일을 열거나 아래의 웹 배포 방식을 이용하세요.

**주의:** 일부 모바일 브라우저는 로컬 파일(`file://`, `content://`)의 저장/클립보드 기능을 제한할 수 있습니다. **장기간 안전하게 사용하려면 HTTPS 웹 배포**를 추천하며, 중요한 데이터는 JSON으로 수시 백업하세요.

## 사용법 B · 휴대폰 홈 화면에 설치하기 (추천)

이 폴더의 파일 전체를 정적 웹사이트 서비스(GitHub Pages, Netlify, Cloudflare Pages 등)에 업로드해 HTTPS로 서비스하세요. 서버 설치나 유료 API 키는 필요하지 않습니다. GitHub Pages 예시:

1. 새로운 저장소를 만듭니다.
2. `index.html`, `app.js`, `styles.css`, `sw.js`, `manifest.webmanifest`, 이미지 파일들을 저장소의 최상위에 올립니다.
3. 저장소 **Settings → Pages**에서 브랜치 배포(`main`, `/root`)를 활성화합니다.
4. 생성된 HTTPS 주소를 휴대폰 브라우저에서 엽니다.
5. 모바일 Chrome의 메뉴에서 **홈 화면에 추가** 또는 **앱 설치**를 사용합니다.

저장소에는 **앱 코드만 올리고 개인/구매한 시나리오 원문 파일은 올리지 마세요.** 앱에서 불러온 시나리오는 해당 기기의 브라우저 저장 공간에서 관리합니다.

## 기술 및 제한

- 순수 HTML/CSS/JavaScript. 빌드·계정·서버·AI API 없이 기본 기능 사용 가능.
- PDF 텍스트 추출 시 PDF.js 3.11.174를 CDN에서 필요할 때 로드합니다. PDF는 최초 사용 시 인터넷 연결이 필요하며, 스캔 이미지 PDF는 OCR 미지원입니다. PDF의 JavaScript 코드 평가 옵션은 비활성화합니다.
- 기존 시나리오에 새 자동 분석 규칙을 적용하려면 **설정 → 원문을 새 규칙으로 다시 분석**을 누르세요. 기존 편집과 진행 기록이 초기화되므로 먼저 **JSON 백업**을 내려받으세요.
- 데이터는 별도 서버로 업로드하지 않습니다. 장치/브라우저별 데이터는 자동 동기화되지 않습니다. 백업을 사용하세요.
- 코코포리아 자동 채팅 전송/API 연동, 코코포리아 주사위 결과 자동 읽기, AI 시나리오 이해·예외 상황 판단은 현재 포함하지 않습니다.
- 파일당 25MB 이하를 권장합니다.
- PWA 오프라인 지원은 HTTPS 또는 localhost 서비스에서만 활성화됩니다.

## 파일 설명

- `index.html` — 화면 뼈대
- `styles.css` — 핑크·아이보리 반응형 디자인
- `app.js` — 시나리오 분석/편집/진행/저장 기능
- `manifest.webmanifest` / `sw.js` — 홈 화면 설치 및 기본 오프라인 캐시
- `icon.svg` / `icon-192.png` / `icon-512.png` — 앱 아이콘

## v1.2: 삼성 갤럭시 멀티윈도우 / 설치형 웹앱

- PWA(Progressive Web App)로 HTTPS 사이트에서 **앱 설치/홈 화면에 추가** 지원. 홈 화면에서 독립 실행할 수 있습니다.
- 작은 창(가로폭 330px 이하 또는 높이 540px 이하+가로폭 900px 이하)에선 **분할 화면 간단 모드**로 자동 전환합니다.
- 상단 **▣ 분할** 버튼으로 간단 모드를 직접 켜거나 끌 수 있습니다. 설정 → **화면 크기에 맞춰 자동**으로 자동 전환 상태로 되돌릴 수 있습니다.
- 간단 모드에서는 하단 메뉴 대신 상단 작은 탭, 축소된 지문 카드, 고정된 복사/이전/다음 버튼이 나옵니다.
- 갤럭시 최근 앱에서 씬플로우(홈 화면 설치 앱)와 코코포리아를 **분할 화면**이나 **팝업 화면**으로 실행해 주세요. 이 기능은 삼성 기기/OS에서 지원하는 경우에 사용 가능합니다.
- 앱을 설치해도 **코코포리아 내부로 자동 발송하지 않습니다.** 복사 후 사용자가 코코포리아 채팅에 붙여넣고 전송합니다.

### HTTPS 배포를 해야 실제로 '설치'됩니다

`씬플로우_v1.2_웹앱.zip`을 압축 해제한 뒤, 내부의 파일(`index.html`, `app.js`, `styles.css`, `manifest.webmanifest`, `sw.js`, 이미지)을 **같은 폴더**에 올리세요. GitHub Pages라면 저장소 최상위(`/`)에 올리고 Settings → Pages → Deploy from a branch → main → /root 로 지정합니다. 홈페이지가 HTTPS로 열리면 모바일 브라우저 메뉴에서 앱 설치/홈 화면에 추가를 선택합니다.

*개별 HTML 파일은 기능을 체험하는 용도로만 제공하며 단독 `file://` 경로에서는 홈 화면 설치·오프라인 기능이 보장되지 않습니다.*
